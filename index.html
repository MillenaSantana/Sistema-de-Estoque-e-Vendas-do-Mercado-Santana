Dicionário de Dados do Mercado Santana

1. Modelo conceitual

Este modelo representa o controle de vendas e estoque do Mercado Santana. A proposta é organizar o cadastro dos produtos, registrar as vendas e acompanhar as movimentações do estoque, facilitando a identificação de produtos que precisam ser repostos.

Entidade Relaciona-se com Cardinalidade
CATEGORIA PRODUTO 1:N — uma categoria pode possuir vários produtos; cada produto pertence a uma categoria.
VENDA ITEM_VENDA 1:N — uma venda pode possuir vários itens; cada item pertence a uma venda.
PRODUTO ITEM_VENDA 1:N — um produto pode aparecer em vários itens de venda.
PRODUTO MOVIMENTACAO_ESTOQUE 1:N — um produto pode possuir várias movimentações de estoque.

CATEGORIA organiza os produtos comercializados pelo mercado em grupos, como alimentos, bebidas, limpeza e itens domésticos.

PRODUTO representa os produtos comercializados pelo mercado.

VENDA representa uma venda realizada pelo mercado.

ITEM_VENDA registra os produtos, suas quantidades e preços dentro de cada venda.

MOVIMENTACAO_ESTOQUE registra as alterações na quantidade dos produtos em estoque.

2. Fluxo de dados

Produto cadastrado → venda realizada → itens da venda registrados → estoque atualizado → consulta do estoque atual → verificação do estoque mínimo → identificação da necessidade de reposição.

3. Dicionário de dados por entidade

CATEGORIA

CATEGORIA = @id_categoria + nome

Leitura: @id_categoria identifica de forma única cada categoria e nome descreve o grupo de produtos.

Atributo Tipo físico Obrigatório Significado e relevância
id_categoria integer Sim (PK) Identifica unicamente a categoria.
nome varchar(80) Sim Nome da categoria, como alimentos, bebidas, limpeza ou itens domésticos.

PRODUTO

PRODUTO = @id_produto + nome + preco_venda + quantidade_estoque + estoque_minimo + status + id_categoria

Leitura: @id_produto identifica de forma única cada produto. id_categoria relaciona o produto à categoria à qual ele pertence.

Atributo Tipo físico Obrigatório Significado e relevância
id_produtointegerSim (PK)Identifica unicamente o produto no sistema.
nomevarchar(120)SimNome utilizado para identificar o produto.
preco_vendadecimal(10,2)SimValor pelo qual o produto é comercializado.
quantidade_estoqueintegerSimQuantidade disponível do produto. Não pode ser negativa.
estoque_minimointegerSimQuantidade mínima utilizada para identificar a necessidade de reposição.
statusvarchar(20)SimSituação do produto, como disponível, vencido ou danificado.
id_categoriaintegerSim (FK)Identifica a categoria à qual o produto pertence.

VENDA

VENDA = @id_venda + data_hora + forma_pagamento

Atributo Tipo físico Obrigatório Significado e relevância
id_vendaintegerSim (PK)Identifica unicamente cada venda.
data_horadatetimeSimRegistra a data e o horário em que a venda ocorreu.
forma_pagamentovarchar(30)SimForma utilizada para realizar o pagamento, como Pix, débito, crédito ou dinheiro.

ITEM_VENDA

ITEM_VENDA = @id_venda + @id_produto + quantidade + preco_unitario + subtotal

Atributo Tipo físico Obrigatório Significado e relevância
id_vendaintegerSim (PK, FK)Identifica a venda à qual o item pertence.
id_produtointegerSim (PK, FK)Identifica o produto vendido.
quantidadeintegerSimQuantidade do produto incluída na venda.
preco_unitariodecimal(10,2)SimPreço de uma unidade do produto no momento da venda.
subtotaldecimal(10,2)SimValor do item, calculado pela quantidade multiplicada pelo preço unitário.

MOVIMENTACAO_ESTOQUE

MOVIMENTACAO_ESTOQUE = @id_movimentacao + id_produto + tipo + quantidade + data_hora + motivo

Atributo Tipo físico Obrigatório Significado e relevância
id_movimentacaointegerSim (PK)Identifica unicamente a movimentação de estoque.
id_produtointegerSim (FK)Identifica o produto que sofreu a movimentação.
tipovarchar(10)SimIndica se a movimentação representa uma entrada ou uma saída.
quantidadeintegerSimQuantidade de produtos movimentada.
data_horadatetimeSimData e horário em que a movimentação ocorreu.
motivovarchar(30)SimMotivo da movimentação, como venda, vencimento ou dano.
