Dicionário de Dados

1. Apresentação

Este dicionário de dados apresenta as entidades, os atributos e os tipos de dados utilizados no Sistema de Estoque e Vendas do Mercado Santana.

2. Entidades e Atributos

2.1 CATEGORIA

Armazena as categorias dos produtos comercializados.

Atributo Tipo de dado Descrição
id_categoria INT Identificador da categoria (PK).
nome VARCHAR Nome da categoria.

2.2 PRODUTO

Armazena as informações dos produtos disponíveis no mercado.

Atributo Tipo de dado Descrição
id_produto INT Identificador do produto (PK).
nome VARCHAR Nome do produto.
preco_venda FLOAT Preço de venda do produto.
quantidade_estoque INT Quantidade disponível em estoque.
estoque_minimo INT Quantidade mínima permitida em estoque.
id_categoria INT Identificador da categoria (FK).

2.3 FORNECEDOR

Armazena os dados dos fornecedores do mercado.

Atributo Tipo de dado Descrição
id_fornecedor INT Identificador do fornecedor (PK).
nome VARCHAR Nome do fornecedor.
telefone VARCHAR Telefone do fornecedor.
endereço VARCHAR Endereço do fornecedor.

2.4 ENTRADA

Registra as entradas de mercadorias no estoque.

Atributo Tipo de dado Descrição
id_entrada INT Identificador da entrada (PK).
data_entrada DATE Data de entrada das mercadorias.
numero_nota_fiscal VARCHAR Número da nota fiscal.
valor_total FLOAT Valor total da entrada.
id_fornecedor INT Identificador do fornecedor (FK).

2.5 ITEM_ENTRADA

Registra os produtos que fazem parte de cada entrada.

Atributo Tipo de dado Descrição
id_item_entrada INT Identificador do item de entrada (PK).
quantidade INT Quantidade do produto recebido.
custo_unitario FLOAT Custo de cada unidade do produto.
subtotal FLOAT Valor total do item.
id_produto INT Identificador do produto (FK).
id_entrada INT Identificador da entrada (FK).

2.6 VENDA

Armazena os dados das vendas realizadas.

Atributo Tipo de dado Descrição
id_venda INT Identificador da venda (PK).
data_hora DATETIME Data e horário da venda.
valor_total FLOAT Valor total da venda.
forma_pagamento VARCHAR Forma de pagamento utilizada.

2.7 ITEM_VENDA

Registra os produtos que fazem parte de cada venda.

Atributo Tipo de dado Descrição
id_item_venda INT Identificador do item da venda (PK).
quantidade INT Quantidade de produtos vendidos.
preco_unitario FLOAT Preço de cada unidade do produto.
subtotal FLOAT Valor total do item.
id_produto INT Identificador do produto (FK).
id_venda INT Identificador da venda (FK).

2.8 MOVIMENTACAO_ESTOQUE

Registra as movimentações realizadas no estoque.

Atributo Tipo de dado Descrição
id_movimentacao_estoque INT Identificador da movimentação de estoque (PK).
tipo VARCHAR Tipo de movimentação realizada.
quantidade INT Quantidade movimentada.
data_hora DATETIME Data e horário da movimentação.
motivo VARCHAR Motivo da movimentação.
id_produto INT Identificador do produto (FK).
id_item_venda INT Identificador do item da venda (FK).
id_item_entrada INT Identificador do item da entrada (FK).

3. Relacionamentos entre as Entidades

CATEGORIA possui relacionamento com PRODUTO por meio do atributo id_categoria.

FORNECEDOR possui relacionamento com ENTRADA por meio do atributo id_fornecedor.

ENTRADA possui relacionamento com ITEM_ENTRADA por meio do atributo id_entrada.

PRODUTO possui relacionamento com ITEM_ENTRADA por meio do atributo id_produto.

VENDA possui relacionamento com ITEM_VENDA por meio do atributo id_venda.

PRODUTO possui relacionamento com ITEM_VENDA por meio do atributo id_produto.

MOVIMENTACAO_ESTOQUE possui relacionamento com PRODUTO por meio do atributo id_produto.

MOVIMENTACAO_ESTOQUE pode referenciar ITEM_VENDA e ITEM_ENTRADA por meio dos respectivos identificadores.

4. Legenda

PK: Chave Primária.

FK: Chave Estrangeira.

INT: Número inteiro.

VARCHAR: Texto de tamanho variável.

FLOAT: Número decimal.

DATE: Data.

DATETIME: Data e horário.
